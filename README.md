# SkillsQuark-DataAnalytics-Internship
Projects and tasks completed during the SkillsQuark Data Analytics Internship, covering data cleaning, sales analysis, SQL queries, and business insights using relevant tools.

TASK 1 - Sales Data Analysis

Project Overview

This project focuses on cleaning and analyzing sales data using Google Sheets.

Work Completed

- Removed duplicate records.
- Identified missing values.
- Calculated sales amounts using Quantity and Unit Price.
- Created a summary of sales data.
- Created a chart to visualize sales by category.
- Recorded business insights from the data.

Tools Used

- Google Sheets
- GitHub

Objective

To organize sales data, identify data quality issues, and summarize sales performance.
